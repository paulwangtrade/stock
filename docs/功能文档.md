## 1. 产品概述

**go-stock** 是一款基于大语言模型的 AI 赋能股票分析桌面工具，支持 **A 股、港股、美股** 的行情查看、资讯聚合、技术分析与 AI 辅助决策（仅供学习研究）。

| 项目 | 说明 |
|------|------|
| 产品 | go-stock 官方桌面版 |
| 后端 | Go 1.26 + Wails v2 |
| 前端 | Vue 3.5 + Vite 7 + Naive UI |
| 数据库 | SQLite（`data/stock.db`） |
| 默认平台 | Windows（macOS/Linux 部分功能受限） |

**核心能力概览：**

- 自选股实时监控、分组、涨跌幅/价格预警
- 全球指数、行业排名、资金流向、龙虎榜
- K 线 / 分时 / 多技术指标
- 财联社 / 新浪等快讯聚合，AI 市场总结
- 自然语言选股、技术面勾选筛选、全市场信号扫描快照
- **纪律化交易台**：5 级大盘仓位模型、市场状态栏、买入/卖出草稿与清单风控
- **信号回测 / 模拟盘**（研究页）：日频回测、本地模拟成交（T+1）
- AI 单股分析、AI Agent 工具调用、浮动 AI 助手
- 交易记录、定时任务、社区分享

## 2. 技术架构

```
┌─────────────────────────────────────────────────────────┐
│  桌面壳：Wails v2（WebView2 / macOS WebKit）              │
├─────────────────────────────────────────────────────────┤
│  前端：Vue 3 SPA（Hash 路由）                             │
│    └── wailsjs：自动生成 Go ↔ JS 绑定（100+ API）         │
│    └── Events：stock_price / newChatStream / agent-message│
├─────────────────────────────────────────────────────────┤
│  后端：app.go + backend/data（行情/新闻/AI/爬虫）          │
│    └── agent：ReAct Agent（CloudWeGo eino）               │
│    └── ai-assistant-web：内嵌 HTTP（:18888）              │
├─────────────────────────────────────────────────────────┤
│  SQLite：data/stock.db                                   │
└─────────────────────────────────────────────────────────┘
```

**通信方式：**

| 类型 | 机制 | 典型场景 |
|------|------|----------|
| 同步调用 | `wailsjs/go/main/App.*` | 查行情、改设置、CRUD |
| 服务端推送 | `runtime.EventsEmit` + `EventsOn` | 实时价、AI 流式输出、快讯推送 |

**子服务：**

| 服务 | 端口 | 说明 |
|------|------|------|
| Vite 开发服 | 5173 | `wails dev` 时前端热更新 |
| Wails DevServer | 34115 | 浏览器调试绑定 API |
| AI 助手 Web | 18888 | `ai-assistant-web`，需 VIP2 |

## 4. 功能模块详解

### 4.1 股票（自选）— `stock.vue`

**入口：** 首页 `/`

#### 4.1.1 自选股管理

| 功能 | 说明 |
|------|------|
| 添加关注 | 右下角搜索框输入代码/名称 → 选中 →「关注」 |
| 分组 | 自定义分组，股票可归属多组 |
| 排序 | 分组内拖拽排序 |
| 取消关注 | 从列表移除 |
| 实时刷新 | 行情定时推送（`stock_price` 事件） |

> **说明：** 自选股列表默认空，需用户手动添加；与「全市场基础股票库」无关。

#### 4.1.2 行情展示

- 实时价、涨跌幅、今开高低、成交量额
- 迷你分时图（`stockSparkLine.vue`）：自选卡仅在进入可视区或 hover 时请求 `GetStockMinutePriceLineData`；父级按 `列数 × 窗口行数` 限制挂载资格，并保留 `content-visibility`
- 盘口数据（A 股）
- 成本价、盈亏、总盈亏汇总（`realtime_profit`）
- 支持 A 股 / 港股 / 美股代码格式

#### 4.1.3 K 线与技术分析

| 功能 | 说明 | VIP |
|------|------|-----|
| 日 K / 周 K / 月 K | 新浪、腾讯、东财等多源 | 基础 |
| 分时图 | 当日走势 + 成交量 | 基础 |
| 技术指标 | MA、BOLL、MACD、KDJ、RSI 等 | 基础 |
| Lightweight 多周期 K 线 | 更完整交互图表 | **VIP2+** |
| K 线天数配置 | 设置中 `openAI.kDays` | — |

#### 4.1.4 预警与通知

| 功能 | 说明 |
|------|------|
| 涨跌幅预警 | 达到阈值触发 |
| 价格预警 | 自定义价格 |
| 本地 Toast | Windows 系统通知 |
| 钉钉推送 | Webhook 机器人 |
| 快讯滚动条 | 底部滚动市场资讯 |

#### 4.1.5 单股 AI 分析

- 对当前股票发起 AI 流式分析（`NewChatStream`）
- 可选提示词模板（系统 / 用户 Prompt）
- 支持思考模式、工具调用（爬取新闻、查价等）
- 分析结果可保存为 Markdown / Word
- 历史记录写入 `ai_response_result` 表

#### 4.1.6 弹幕

- WebSocket 连接作者服务器弹幕频道（可开关）
- 设置项：`enableDanmu`

#### 4.1.7 其他

- 分享分析到社区（上传作者服务器）
- 打开外部链接（东财行情页等）
- 全屏 / 窗口主题随设置

## 12. 量化交易能力（演进）

> 定位：**决策辅助 + 模拟盘**。默认不自动实盘下单；券商通道为人工确认适配层。

### 12.1 5 级仓位模型与市场状态栏

- 规则：`frontend/src/utils/tradingLevelRules.js`（语义版本 `LEVEL_SEMANTICS_VERSION=2`，level1 空仓防守 → level5 重仓攻击）
- 与设置总敞口合并：`positionPolicy.js`（`signalParams.automation.maxTotalExposurePct`）
- 顶栏：`MarketStatusBar.vue` 展示交易时段、总级别、分市场级别、纪律仓位上限、账户持仓占比
- 校验：`npm run test:position-model`（`frontend/scripts/verify-position-model.mjs`）

### 12.2 量化自动化与风控

- 配置统一持久化在 `Settings.signalParams` → `automation`（`quantAutomationSettings.js`）
- 关键开关：`blockNewEntriesOnDefense`（1/2 级禁开仓）、`requireChecklistForBuyConfirm`（买入确认须清单就绪）
- 自选卡可「生成买入/卖出草稿」→ 研究页「交易日志」确认；确认买入受风控门禁（`riskGate.js`）

### 12.3 全市场信号扫描与我的策略

- 全市场快照：`signal_scan_snapshots` + `RunSignalScanSnapshot`
- 本地策略：研究页「我的策略」（`stock_strategies` / Cron 执行）

### 12.4 信号回测

- 研究页「信号回测」：日频引擎 `backtestEngine.js`（佣金/印花税/滑点/整手/T+1，可选 5 级纪律对照）
- K 线优先走东财接口，后端已有 `kline_cache` 表缓存

### 12.5 持仓口径与持仓做T

- 底部「持仓股」严格区分两个账户口径：
  - 自持仓：用户在自选股中手工录入的 `followed_stock.volume/cost_price`
  - 量化仓：模拟执行账户 `paper_positions`，不与自持仓合并统计
- 「持仓做T」只读取自持仓，使用 5 分钟 K、VWAP、MA5、RSI14 和量能共振给出 T入/T出参考。
- 做T提示遵守连续竞价时段、100 股整手、每天最多两轮；真实可卖数量无法确认时必须人工核对。
- 做T功能默认只提示，不自动实盘下单，测算结果不构成投资建议。

### 12.6 量化执行台与券商适配

- 底部「量化交易」统一展示模拟/未来实盘的账户、持仓、委托、成交和权益。
- 模拟盘：`paper_accounts` / `paper_positions` / `paper_orders` / `paper_fills` / `paper_equity_points`
- API：`SubmitPaperOrder`（可立即撮合）、`SettlePaperSellable`（T+1）、`ResetPaperAccount`、`SetPaperMarkPrice`（市价估值）
- 统一 `ExecutionAdapter` 与 `tradingEvent` 事件流将模拟成交标准化为委托、成交、持仓、账户事件，前端按毫秒时间显示。
- 两融模拟（首期）：`backend/risk` + `backend/execution` + `paper_margin_*` 表；API：`GetPaperMarginSnapshot` / `SubmitPaperMarginOrder` / `AccruePaperMarginInterest` / `RunPaperMarginRiskScan`；默认警戒线 1.5、平仓线 1.3（**仅本地模拟阈值，非监管标准**）。
- 未来实盘券商只需实现相同适配器；默认 `ManualConfirmAdapter` 仅记录人工确认，不真实下单。

### 12.7 市场等级显示约定

- 内部风控与用户界面永久统一为 **1级最防守、5级最进攻**，展示数字与内部等级恒等，不再做反转。
- 旧字符串模式仅作输入兼容：`attack → level5`、`neutral → level3`、`defense → level2`；所有新数据与计算统一使用 `level1` 至 `level5`。

### 12.8 演进阶段落地状态

| 阶段 | 范围 | 状态 |
|------|------|------|
| Phase0 | 配置统一、文档、`npm run test:quant` | 已完成 |
| Phase1 | 市场状态栏、五级仓位、草稿闭环、硬风控 | 已完成 |
